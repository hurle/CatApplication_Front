# CatApplication_Front
Web application that uses Angular and integrates TheCatAPI to perform: Cat search by breed. Limitation of the number of results. Display images depending on the previous parameters.

COMPILATION INSTRUCIONS

1.- Install Node.js and npm. To verify if the instalation is already done ejecute the comands: "node -v" and "npm -v" in the powershell console.

2.- Clone the repository in the local machine.

3.- Open the folder in the terminal into the folder where is located the package.json file

4.- Execute npm install (May take a few minutes)

5.- Execute the command npm run start

To create a deploy build repeat execute the command: npm run build:prod
